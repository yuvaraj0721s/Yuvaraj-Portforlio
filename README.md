# Yuvaraj R — Cybersecurity Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Personalize before publishing
1. Open `script.js` and update `PROFILE.linkedin`, `PROFILE.instagram`, and `PROFILE.email`.
2. Add your real resume PDF at `assets/Yuvaraj_R_Resume.pdf`.
3. Replace generic GitHub profile links on project cards with specific repository URLs when those repositories exist.
4. Verify all credential statuses and achievement ranks before sharing.
5. Add real reel links and thumbnails if you want the content cards to open specific posts.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `yuvaraj-cybersecurity-portfolio`.
2. Upload all files and folders in this project to the repository root.
3. Open repository **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and use the URL shown in the Pages settings.

## Notes
- The portfolio intentionally does not invent an email address, LinkedIn URL, Instagram URL, or individual project repository URL.
- CompTIA Network+ and Security+ are marked as currently learning, not completed certifications.
- Spectrona 2026 is listed as 52nd place per the requested update.


### Profile photo
A portfolio-ready portrait is included at `assets/yuvaraj-profile.png` and displayed in the homepage hero section. Replace this file with your preferred image using the same filename to update it.
